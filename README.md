# Просмотр результатов моделирования

Локальный сайт показывает файлы из этой папки: 3D-модели GLB, GIF, SVG, CSV, документы и модели COMSOL.

## Запуск

Требуется установленный Python 3.

```bash
python app.py
```

Откройте в браузере: <http://127.0.0.1:8000>

Можно запустить `start.bat` двойным щелчком. Для остановки сервера нажмите `Ctrl+C` в окне терминала.

## Возможности

- автоматическое сканирование текущей папки;
- группировка и поиск результатов;
- просмотр GLB с вращением и масштабированием;
- просмотр GIF, SVG и изображений;
- отображение CSV в таблице (до 2 000 строк одновременно);
- скачивание исходных файлов;
- светлая и тёмная темы.

3D-просмотрщик загружается с Google CDN, поэтому для первого открытия 3D-моделей требуется интернет.
